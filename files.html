Radio Freedom Architecture & Operational Workflow

This document provides a simple, universal overview of the lightweight, high-efficiency data pipeline powering the Radio Freedom historical preservation archive and independent record shop.

1. The Core Philosophy: Serverless Efficiency

Unlike standard modern websites that rely on slow, expensive corporate database servers, this system uses a flat-file architecture. The frontend interface runs instantly inside the user's web browser by reading a single text-based index file (pop.json). This approach eliminates server fees, protects the website from crashing, and guarantees that the digital archive remains completely portable and immune to platform modifications.

2. The Four-Stage Automation Pipeline

The daily production line is broken down into four distinct, independent micro-tasks to ensure perfect data integrity:

  • Stage 1: Inventory Control (playlist.py) - An offline curation tool that scans the local hard drive, converts complex filenames into clean text signatures, cross-references them against master checklists, and automatically strips out duplicates before any downloads occur.
  • Stage 2: Targeted Extraction (mp3-get2.py) - A sequential download engine that extracts audio streams directly from web sources using a linear index-stepping loop. It re-writes filenames using a uniform dotted schema and enforces safe processing intervals to remain completely invisible to network security blocks.
  • Stage 3: Digital Asset Hosting (GitHub Releases) - Audio files are stored completely outside the main codebase inside a high-speed cloud drive attached to the repository. This storage system provides unlimited bandwidth, allows massive file sizes, avoids automated bot takedowns, and streams bytes instantly to the web player over a global developer Content Delivery Network (CDN).
  • Stage 4: Database Compilation (test2.py) - An offline assembly script that reads the final filenames from the disk, extracts clean display fields for the website, maps the permanent download paths, and logs the records straight to the local pop.json file without network lag.

3. Master Studio DSP Engineering (Boiling Frog Module)

To preserve original vinyl recordings and create unique intellectual property under English law, the archive utilizes advanced Digital Signal Processing (DSP) via a dedicated master studio simulation console:

  • Surgical Bandwidth Filtering - Lowpass filters systematically isolate instrument frequencies and remove unwanted mechanical turntable rumble or high-end surface tape hiss.
  • The Boiling Frog Module - A custom mathematical saturation curve that gradually and exponentially increases vacuum tube harmonic density across the timeline of the song, transforming the transfer into a distinct, proprietary audio work.
  • Acoustic Room Glue - A dedicated time-delay algorithm that simulates the live room acoustics of early historical recording studios, seamlessly blending separate tracks back into a cohesive, vintage mono environment.

4. The Inaudible Security Fingerprint (Ultrasonic Watermark)

To protect the restored audio masters from unauthorised scraping or copying, every single file is locked down with a hidden digital tracking signature before publication:

  • Ultrasonic Carrier Signal - A permanent tone is injected at exactly 20,000 Hz, sitting safely at the absolute technical limit of digital audio files. This frequency is completely outside the range of human hearing, ensuring the audio quality is perfectly preserved for listeners.
  • Morse Code Encryption - The high-frequency tone turns on and off at precise millisecond boundaries, spelling out "SECTION 23 MP3" inside the three-second silences at the beginning and end of the track.
  • Forensic Math Verification (verify.py) - While standard media players mask this frequency, a custom verification script runs a Fast Fourier Transform (FFT) calculation to separate the sound into mathematical columns. It reads the raw bytes instantly and prints a definitive validation readout if the signature is present.
